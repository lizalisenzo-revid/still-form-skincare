# Still Form skincare storefront

A separate storefront built from the existing RevID React/Vite commerce foundation. Coming-soon by default, with no purchasable placeholder products.

Run `npm ci`, then `npm run dev`. Run `npm test` and `npm run build` for checks.

Read [the handoff guide](docs/README.md) for integration findings, required approval, product fields, branding, domain setup, verification and launch gates. [The proposed shared SQL](database/proposed-shared-schema.sql) has **not** been applied. [The legacy webhook patch](docs/proposed-legacy-webhook.patch) has **not** been deployed.
